# Яндекс LMS внутри VS Code

Расширение для VS Code: задания и уроки курса **«Программирование на Python»** (и других курсов Яндекс LMS) прямо в редакторе — условие слева, код справа, отправка решения на проверку в один клик, помощь ИИ и проверка PEP 8.

## Возможности

**Задания**
- дерево: курсы → уроки → задания, с иконками статуса (✓ зачтено, ⟳ на проверке, ✎ на доработку);
- условие задачи с форматированием, таблицами и **картинками** (в том числе картинками с кодом из `storeContainer.resources`);
- файлы решений создаются рядом в папке `yandex-lms`, шаблон `def main(): pass` вырезается;
- отправка решения на проверку (`POST /api/student/solutions/<id>/comments/files`) и ожидание вердикта;
- «Подробности проверки» — вердикт, лог компиляции, время/память, номер теста, ввод, ожидаемый результат, вывод, сообщение проверки;
- задания с вариантами ответа (`schoolbook_markers`) — вопрос, варианты и отправка ответа.

**ИИ (по желанию)**
- **Подсказки** — пошаговый план решения по условию (без готового кода);
- **Проверить** — разбор решения: логика, граничные случаи, вердикт;
- **Решение** — эталонный код по правилам курса;
- **Исправить** — чинит код по ошибке проверки, учитывая замечания LMS;
- **Выбрать ответ** — для заданий с вариантами;
- **Память ошибок** — ИИ запоминает, на какие грабли наступали (в т.ч. «списки и индексы строк будут немного позже»), и не повторяет их;
- **Автодополнение в редакторе** — следующая строка решения подсказывается прямо при наборе кода (inline completion);
- провайдеры: OpenRouter, Mistral, OpenAI, Ollama (локально) и любой OpenAI-совместимый API.

**Проверка кода**
- кнопка **PEP 8**: `pycodestyle`/`flake8`, если установлены, иначе `py_compile` (синтаксис) и встроенный набор проверок (E501, W291, W191, E111, E225, E251, E302, E303, W292).

## Установка

```bash
# сборка пакета
bun x @vscode/vsce package --no-dependencies --allow-missing-repository
# или
npx @vscode/vsce package --no-dependencies --allow-missing-repository

code --install-extension yandex-lms-1.3.3.vsix
```

Требуется Node.js 18+ (для сборки) и VS Code 1.85+.

## Вход

Три способа:
1. **QR-код** — команда `LMS: Войти по QR-коду`: открывается панель с QR, сканируется приложением Яндекс, пароль и 2FA не нужны;
2. **логин и пароль** — `LMS: Войти (логин и пароль Яндекса)`, аккаунт без 2FA;
3. **cookie** — `LMS: Войти по cookie`, если включена 2FA.

Cookie хранятся в `SecretStorage` VS Code, а не в файлах настроек.

## Настройки

| Параметр | Описание |
|---|---|
| `yandexLms.apiBase` | адрес LMS (по умолчанию `https://lms.yandex.ru`) |
| `yandexLms.folderName` | папка для файлов решений (по умолчанию `yandex-lms`) |
| `yandexLms.pythonPath` | путь к Python для локального запуска и PEP 8 |
| `yandexLms.pollSeconds` | сколько ждать вердикт после отправки (по умолчанию 60) |
| `yandexLms.taskView` | `panel` (по умолчанию) / `text` / `auto` — как показывать условие |
| `yandexLms.ai.provider` | `openrouter` / `mistral` / `openai` / `ollama` / `custom` / `none` |
| `yandexLms.ai.apiKey` | API-ключ провайдера |
| `yandexLms.ai.model` | модель (для OpenRouter — например `deepseek/deepseek-chat`) |
| `yandexLms.ai.baseUrl` | базовый URL API для совместимых провайдеров |
| `yandexLms.ai.autocomplete` | ИИ-автодополнение в редакторе (вкл/выкл) |
| `yandexLms.ai.autocompleteDelay` | пауза перед запросом подсказки, мс |
| `yandexLms.ai.autocompleteMaxCalls` | максимум запросов к ИИ в минуту |

Провайдера удобнее настроить прямо из расширения: `LMS: AI — настройки провайдера` (выбор провайдера, ключ, модель, список моделей с сервера).

## Основные команды

| Команда | Действие |
|---|---|
| `LMS: Открыть задание` | открыть условие и файл решения |
| `LMS: Отправить решение` | отправить код на проверку (Ctrl+Alt+S) |
| `LMS: AI — подсказки / проверить / решение / исправить` | помощь ИИ |
| `LMS: Проверить код на PEP 8` | проверка стиля |
| `LMS: Подробности проверки` | что ответила проверка |
| `LMS: Ответить на задание` | выбрать вариант ответа |
| `LMS: Найти задания с картинками` | диагностика: где в курсе есть изображения |
| `LMS: Собрать отчёт для отладки` | отчёт по API в `%TEMP%\yandex-lms-diag` |
| `LMS: Починить webview` | очистить состояние service worker профиля VS Code |

## Отладка

Всё пишется в `%TEMP%\yandex-lms-diag`:
`webview-log.jsonl` (панель), `ai-log.jsonl` (запросы к ИИ), `submit-log.jsonl` (отправка решений), `images-scan.json` и `task-descriptions.json` (скан заданий на картинки), `problem-definition.json`, `lesson-tasks-*.json`.

## Известная особенность VS Code 1.142

В VS Code 1.142 при перезагрузке окна первый webview может не загрузиться с ошибкой
`Could not register service worker: InvalidStateError` (баг VS Code, [microsoft/vscode#342842](https://github.com/microsoft/vscode/issues/342842) — ломает и встроенные расширения).
Расширение обходит это: фокусирует панель, отдаёт HTML с задержкой, чистит состояние service worker и при неудаче переключается на текстовый вид условия. Команда `LMS: Починить webview` чистит состояние вручную.
